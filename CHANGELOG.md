# Changelog

## 0.2.0 — 2026-09-05

First Integrated Preview: repository installer with preservation, dry-run, update
and removal; canonical participant policy; typed state/configuration; deterministic
GitHub evidence and bounded reports; automatic Review Brief; separate review;
durable agent/human clarification; and optional schema-validated model interpretation.

Controlled real GitHub events verified automatic drafting, answers and staleness.
Codex handoff and fresh-agent takeover were exercised, and two real OpenAI calls
validated draft/review output. 94 tests passed; independent engineering review found no unresolved material
implementation findings.
Human authority is never inferred; real-team effort reduction remains unvalidated.
Publication is complete only when the immutable tag and GitHub Release exist.

## 0.1.0 — Concept Preview

Initial manual prototype validating the Passport information model:

- Core Markdown Passport and copyable GitHub PR section.
- None, Light, Standard and High-consequence guidance.
- Fictional examples and evidence-grounded draft/review prompts.
- Team trial guide, Apache-2.0 and repository quality controls.

First-user evaluation found manual authoring too burdensome for consistent adoption.
This useful product evidence motivates v0.2.0's repository integration, automatic
drafting and clarification loop. v0.1.0 is not recommended as a complete operational
integration. Its immutable tag is preserved.

Publication is tracked in [GitHub Releases](https://github.com/suyog19/software-signal-passport/releases).
