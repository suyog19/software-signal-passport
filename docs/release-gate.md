# v0.2.0 release gate

Candidate version is 0.2.0. It is not yet a published release.

## Evidence required before publication

1. Exact candidate and process revisions classified/evaluated; selected validation,
   architecture, functional/non-functional and independent review evidence retained.
2. Installer dry-run, preservation, update/removal, configuration/handoff schemas,
   deterministic collection, answer lifecycle, negative and security tests pass.
3. CI quality and process configuration checks pass; green structural checks must
   not be relabelled authenticated process readiness.
4. Independent fresh-context review has no unresolved material implementation findings.
5. Trusted default-branch installation triggers automatically on PR and comment events.
6. Dogfood demonstrates evidence, draft, separate review, questions, agent response,
   human escalation, new-commit staleness, re-review and honest final advisory state.
7. Real provider path tested with authorized credentials, separately from mocks.
8. Canonical Software Signal update reviewed and merged with accurate status.
9. Owner performs required manual promotion under the canonical process.
10. Revalidate merged default branch and prepare annotated immutable v0.2.0 tag.
11. Publish First Integrated Preview with installation, protocol, security, dogfood
    and limitations links. Verify source archives, tag, version and links.

Do not close the release issue or publish a misleading release while a gate is
unverified. The intended label is **First Integrated Preview**; controlled tests
do not establish the external validation needed for Integrated Beta.

## Maintainer sequence after the manual boundary

Use the reviewed installation to open a controlled draft PR, submit a valid handoff,
answer a technical question, verify comment-event handling and add a commit to
verify staleness. Preserve unresolved human authority rather than invent acceptance.
Attach the resulting exact revisions and run links to the release issue.

Repository protections and the canonical human boundary remain in force. Agents
may prepare and verify artifacts; they cannot pretend a manual owner action occurred.
