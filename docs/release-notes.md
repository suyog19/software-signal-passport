# Software Signal Passport v0.1.0

Prepared release notes; this file does not establish publication.

Software Signal Passport carries the intent, context, provenance, evidence,
uncertainty and accountable ownership a reviewer needs beyond the diff.

- [Five-minute quick start](https://github.com/suyog19/software-signal-passport/blob/v0.1.0/README.md#five-minute-quick-start)
- [Copy the core template](https://github.com/suyog19/software-signal-passport/blob/v0.1.0/templates/software-signal-passport.md)
- [GitHub PR section](https://github.com/suyog19/software-signal-passport/blob/v0.1.0/templates/github-pr-passport.md)
- [Completed fictional examples](https://github.com/suyog19/software-signal-passport/blob/v0.1.0/examples/README.md)
- [Five-change team trial](https://github.com/suyog19/software-signal-passport/blob/v0.1.0/docs/team-trial-guide.md)

Free and openly usable under Apache-2.0. Markdown only: no hosted service, model
API, telemetry or runtime installation. Light, Standard and High-consequence
guidance scales detail to consequence; trivial edits can omit a Passport.

This initial version is advisory and unvalidated in real-team trials. Examples
are fictional. A completed Passport is not certification, proof of correctness,
safety or compliance, or approval to merge. Try it on representative real changes
and share sanitized observations before proposing automation.
