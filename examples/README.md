# Completed examples

**Every organization, repository, person, ticket, commit label, policy, command
result and evidence record in these examples is fictional.** They are teaching
fixtures, not tests executed against a real system or claims of adoption.
Identified records below are provided inline so there are no fake live links.

- [Low-risk internal refactor](low-risk-refactor.md): Light, short and reversible.
- [Payment retry behavior](payment-retry-change.md): High-consequence, with
  concurrency evidence and a provider verification gap.
- [Refund eligibility](refund-eligibility-change.md): High-consequence, with
  policy exceptions and unresolved partial-refund authority.
- [API pagination](api-pagination-change.md): Standard, an additive interface
  change with compatibility and operational considerations.

Each example separates simulated performed checks from proposed work. Some
remain unsuitable for merge or rollout; a completed Passport can honestly expose
that state.
